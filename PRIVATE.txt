WHY THIS FILE EXISTS
--------------------
open-ocean is built as a PRIVATE repository on purpose. It ripens here -
manifests, installer wiring, branding, README - and goes public only at the
moment the sluice is opened. Until then every form of publication is barred:
GitHub visibility public, public forks or mirrors, registry and marketplace
entries, package publishes, public websites carrying this content.

Editing the repository is explicitly allowed. This is a publication lock, not
a work lock.
